This article is for Tournament owners and admins. It shows you how to tell QView what type each question in a Round is (General, According-to, Quote, and so on). When you’re done, every Round in your Division has its 20 question types saved.

Why bother? Question types are what let QView:

  • break each Team’s and Quizzer’s stats down by question type (see Computing Stats), and
  • use the Memory Verse (M) Correct tie-breaking rule.

Before you start:

  • You need to be able to edit the Tournament’s schedule. Tournament managers and admins can.
  • The Division needs its Rounds already (see Scheduling Rounds and Games).
  • To fill them in from a file, have the question set file (.rtf or .csv) that came with your questions.

What are the question types?

Each question gets one of these codes:

  • G: General
  • A: According-to
  • Q: Quote
  • R: Reference
  • V: Verse
  • X: Context
  • S: Situation
  • I: In what Book and Chapter

A standard 20-question set has 11 G, 4 A, one each of Q, R, V and X, and one S or one I (never both).

M (Memory Verse) isn’t a type you pick. QView counts every R, Q and V question as a Memory Verse question for you, so a standard set has 3.

Where do you set them?

Question types are always set in the Set Question Types dialog. It lists every Round of the Division, so you can set the whole Division at once or fix just one Round. The button is in four places, and they all open the same dialog:

  • Schedule > Create / Edit, next to Edit Start Times.
  • The Division’s Rounds page.
  • Server Stats, with Data set to Team Stats, next to Tie-breaking Rules.
  • The top bar of the Edit Round dialog, next to Save (see Setting one Round below).

Setting every Round at once

  1. Click Set Question Types. Every Round of the Division is listed, in schedule order, showing what it has saved.
  2. For each Round, pick each question’s type from its dropdown. Or click Import from file to fill them in (see below).
  3. Check the colored count chips above each Round (see What do the colored chips mean? below).
  4. Click Save Question Types.

Every Round is saved together. If any Round has a problem, nothing is saved, and the problem is shown in red above that Round. Fix it and click Save Question Types again.

Filling them in from a question set file

  1. In the Set Question Types dialog, click Import from file.
  2. Choose your question set file (.rtf or .csv).
  3. Each Round picks up a set from the file, in order: the first set goes to the first Round, the second set to the second Round, and so on.
  4. Check each Round. To use a different set for a Round, choose it from the dropdown next to the Round’s name. Choose No set — keep current question types to leave that Round as it was.
  5. Click Save Question Types.

Nothing is saved when you import. You can still change any question by hand before you save.

Say the file has 12 sets but the Division has 10 Rounds. A yellow message tells you the last 2 sets won’t be used unless you pick them for a Round. If the file has fewer sets than you have Rounds, the extra Rounds keep what they have.

Setting one Round

When you’re already looking at a Round, open the dialog from that Round, and QView marks it for you.

  1. Open the Round’s Edit Round dialog. You can get there in two ways:
    • Schedule > Create / Edit: pick the Division, then click Edit Round on the Round.
    • The Round’s own page: click Edit under its name.
  2. In the top bar, click Set Question Types.
  3. Find the Round marked This round. Make sure Question Types is ticked, then pick a type for each of the 20 questions.
  4. Click Save Question Types.

The other Rounds are listed too, but they keep what they have unless you change them.

Question types are saved on their own, when you click Save Question Types. The Edit Round dialog’s Save button doesn’t save them, so you can close Edit Round afterwards without saving it. A Round you’re still creating isn’t in the list yet: save it first, then set its types.

If a Round has question types and you untick its Question Types, clicking Save Question Types removes them. QView doesn’t ask first.

What do the colored chips mean?

Above the questions, a chip for each type shows how many you’ve picked against a standard set, for example G: 11/11. S/I counts S and I together, and M shows the Memory Verse count worked out from R, Q and V.

  • Green: exactly the standard count.
  • Orange: fewer than standard.
  • Red: more than standard.

Hover over a chip to see the type’s full name.

What if your question set isn’t standard?

Untick Use standard question type counts for that Round. QView then saves any mix (only G questions, say), and the chips just show counts. Every question still needs a type.

How do you know it worked?

Open Set Question Types again: every Round shows its saved types. When every Round in the Division has them, you can tick the Memory Verse (M) Correct rule in Tie-breaking Rules.

When it doesn’t work

  • “Every question needs a question type (missing: …)” A Round has types for only some questions. Pick the missing ones, or untick Question Types for that Round to save it without any.
  • “Expected 11 G (General) question(s), found 10.” (or another type) The Round doesn’t match a standard set. Fix the questions, or untick Use standard question type counts if the set really is different.
  • “A standard question set can't contain both S (Situation) and I (In what Book and Chapter) questions.” Change one of them, or untick Use standard question type counts.
  • “Only .rtf and .csv question set files can be imported.” Choose the .rtf or .csv file that came with your question sets.
  • “No questions were found in the file.” or “The CSV has no "Type" column.” The file isn’t a question set export, or it was changed in a spreadsheet. Get a fresh copy of the file.
  • A set is marked “(unreadable)”. Something in that set couldn’t be read (a missing question, or a code that isn’t a question type). Its Round keeps what it has, and a yellow message says what was wrong. Set that Round by hand.
  • “This division has no rounds yet. Add rounds first.” Create the Division’s Rounds first (see Scheduling Rounds and Games).
  • The Round you’re creating isn’t in the list. It hasn’t been saved yet. Save it first, then open its Edit Round dialog and click Set Question Types again.
  • There’s no Set Question Types button in Create Round. Pick the Round’s Division first. The button shows up once it has one.
  • The button is greyed out on Server Stats. You’ve picked a Stats Group that isn’t a Division’s. Question types belong to a Division’s Rounds, so pick that Division’s Stats Group, or use the button in the schedule editor.
  • You don’t see the button at all. Your account can’t edit this Tournament’s schedule. Ask the Tournament’s owner.
