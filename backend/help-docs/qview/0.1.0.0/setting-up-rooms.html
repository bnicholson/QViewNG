You’ve set up your Tournament, Registration has closed and it’s the (first) morning of the Tournament. You need to set up your quiz rooms so that when the first Round starts, everything goes smoothly.

Ahead of time, if you are having your various Teams bring their Gear for use at the Tournament (which has been registered for use at the Tournament), then they will need to arrive early enough for this setup. Typically 1 hour before the first Round begins works for a regular sized Tournament. With larger Tournaments you may need more time and perhaps some setup the day before.

If you are using QView then you are also using QuizMachine on computers (usually laptops), 1 per Room (plus other Gear; this article assumes you know how to set that Gear up as needed).

Before you start

  • QuizMachine 6.3.0-e76 or newer on every Room’s computer. Older versions of QuizMachine will not work with QView. For the latest install of QuizMachine please see QuizStuff.com.
  • An internet connection in each Room. (If a Room can’t get online, see importing its Games afterwards.)
  • The Tournament set to Public. QuizMachine can’t see Private Tournaments.
  • The Tournament’s Pairing Code. It’s on the Tournament’s Overview page (click the eye icon to show it). See Creating a Tournament.
  • Rooms and a schedule in QView, so each Room has Games to load (see Post-Registration Prep: Rounds and Games).

Pointing QuizMachine at QView

Once installed, start the QuizMachine desktop application (client). We will need to be using the QView configuration along with the address of the QView website for communicating data to it.

  1. Click More or press the M key to pull up the More Menu. Then click Setup.
  2. At the top of the Setup window, click the second tab, Server/Sneakernet.
  3. Set the Server to QView and the IP address to qview.teenbiblequiz.com.
  4. Leave Tournament key and Physical Bldg/Room blank. QView doesn’t use them: you’ll enter the Tournament’s Pairing Code and pick the Room in a later step instead.
  5. Click OK to apply the changes and close the Setup window. (You do not need to click Apply before clicking OK.)

Choosing the Tournament and Room

  1. Click More or press M again. Now click Start a Tournament.

    QuizMachine will get the available Tournaments from QView. If this is successful you will very briefly see a loading pop-up window, then the Tournament picker:

  2. In the first column, select your Tournament. The list shows Public Tournaments from about 1 month in the past to 1 month in the future. The second column shows the selected Tournament’s Short Information, which helps you check it’s the right one.
  3. In the third column, select the Room that this QuizMachine computer is for.
  4. Enter the Tournament’s Pairing Code in the Pairing Code field. This is a security measure: only people with the Pairing Code can “pair” a QuizMachine client with that Tournament in QView. It also protects you from connecting to the wrong Tournament, since that Tournament’s code won’t match.
  5. Click Join.

Checking the first Game’s lineups

On success you will see the Lineups window appear with the first Game of that Room populated:

QView fills in the seats for you, but feel free to reorder each Team’s Quizzers by moving them to different seats as needed. You may also need to change their Captain/Co-captain designations. When ready, click OK to save the changes, close the Lineups window and load the Game.

You are now ready to use this Room for the first Game of the Room!

How do you know it’s working?

Back in QView, open the Tournament and click Server Monitor in the sidebar. Every Room that has connected appears there with a recent Check In time. Once a Game starts, it also shows on LIVE Stats under Games in Progress. See Monitoring Rooms and Resending Game Data.

When it doesn’t work

If the Tournament list doesn’t load, you’ll see an error instead:

  • The error above appears. Either the server settings aren’t right (usually a typo in the address), or QView or the internet connection isn’t available. More often than not it’s the first: re-check the Server/Sneakernet tab. In the example above, the address was typed with a comma instead of a period (qview,teenbiblequiz.com), so QuizMachine couldn’t find QView.
  • Your Tournament isn’t in the list. Either its dates aren’t within about a month of today, or it is set to Private (the default). Fix either one in the Tournament’s Edit form, from its Overview page.
  • Your Room isn’t in the list. Check that the Room exists on the Tournament’s Rooms page.
  • Join fails. Check the Pairing Code on the Tournament’s Overview page. If the code was changed recently, use the new one.
  • The Lineups window is empty, or shows the wrong Game. Check the Room’s Games on the Tournament’s Schedule page. Games are loaded in order of their Round’s start time.

When a QuizMachine client is loaded as a certain Room of a Tournament, QuizMachine sees the Games as completely new with no history. QView, however, may already have some history for those Games if a different QuizMachine was connected as that Room and was used earlier.
