If you haven’t added your Rooms (and/or Buildings) yet, you will need to do so now before proceeding. Take a look at the section on adding Rooms to a Tournament in this article. If your Tournament uses more than one building, assign each Room to its Building too, so people can filter the Schedule by Building.

In QView, the Scheduling module has 2 modes: “Normal” and “Advanced”.

Normal Mode deals only with Rounds and Games.

Advanced Mode includes what is included in Normal Mode and adds to it Sessions, Pools, Brackets, PoolGroups and BracketGroups.

Both Scheduling modes can be used to achieve the same goal. Advanced Mode is more for organization of large schedules in an effort to make the sheer amount of Games and Rounds make more sense in their given planned contexts.

With this being said, let’s cover the basics - Normal Mode:

Normal Mode

Let’s start with terms.

A Game in QView is a standard 20-question quiz set asked to 2 or 3 Teams of Quizzers by a quizmaster (in Nazarene-style teen Bible quizzing).

A Round is a fundamental, time-based grouping of Games. Each Round will therefore have a different time than the other Rounds of its Division.

An important note: Each Division has its own set of Rounds, from a data perspective. You may be used to seeing a schedule table that looks something like this:

..except with more Rooms and with multiple Divisions. This last part deserves clarity concerning QView: Rounds don’t span multiple Divisions in QView. This is a deliberate design choice so that scheduling is encapsulated to the scope of the Division. At the same time, it is a design decision to NOT require the Division to (otherwise) be tied to a Round such that the Round’s Start Time is shared across Divisions, creating inflexibility in scheduling across all Divisions of the Tournament.

Since the Round has to have a single Start Time, it was decided to allow Divisions to have their own Rounds and, therefore, their own Start Times to allow for more flexible scheduling in-Division.

In Normal Mode, all that is needed for scheduling is Rounds and Games. Games get their Start Times from the Round they are assigned to. Without Rounds, Games have no scheduling context.

One of the most popular scheduling styles is Round-Robin matchups. In the examples here we will be using 2-team Game matchups since they are most common. There are some added complexities for 3-team Game matchups which will be addressed later.

Let’s get started! Go to your Tournament and click Scheduling. Then click “Create / Edit” at the top:

Here you will see the following:

  1. Mode: Controls toggle between “Normal” and “Advanced” mode. This is a setting at the Tournament level which is updated whenever it is changed by any user with access to it. Data for both modes is the same underneath; you can use either mode interchangeably.
  2. Divisions in a tabbed row: Select which Division to create/edit the schedule of.
  3. ‘Create Schedule’ button: Use this to create Rounds and Games (or more in Advanced Mode) in a Round-Robin or Tournament Bracket configuration.
  4. ‘Add Round’ button: Add a single new Round to the current list of Rounds.
  5. ‘Edit Start Times’ button: Edit the Start times of all Rounds in bulk with a given Round duration (default = 30 minutes). (The default Round duration is set at the Tournament-level.)
  6. Filter: Select/Deselect which Games are shown in the schedule. This does not delete the items, it only hides them.
    • For example, clicking ‘Room 9’ in the screenshot above will make Games that happen in Room 9 disappear. Clicking it again brings them back.
    • Clicking the ‘eye’ icon will cause all Rooms (or Teams) to be hidden, effectively hiding all Games. Click it again to bring them back. When some are hidden, clicking the ‘eye’ icon makes all items visible again.
    • When the ‘Show Round When Empty’ checkbox is selected, the Round will remain visible even when there are no Games currently showing in its Round. When deselected, the Round also disappears when all of its Games are hidden.
    • Clicking the ‘Reset/Show All’ button resets the filter so that all Games of the Division are visible. Use this if you ever feel like you may be missing something.
    • Note: The ‘Teams’ filter works a little differently than the other filter options. Since there are two/three Teams per Game, hiding one Team normally won’t hide any Games. Hiding a 2nd Team will hide all Games where those two Teams compete without a third Team, if any exist.
  7. Round: This is the time-context for the Game. In it you can:
    • ‘Add a Game’: Add a new Game to that specific Round.
    • ‘Edit Round’: Allows you to edit the Round’s details.
    • ‘Delete Round’: Allows for deleting the Round from the Division.
  8. Game: This is the 2- or 3-team matchup of 20 questions. Click the Game to enter the editor for the Game. In the editor you also have the options to:
    • ‘Delete’: Delete the Game.
    • ‘View Game’: Navigate to the Game’s profile.
    • ‘Save’: Save the edits made to the Game.

Create Schedule button

It is recommended that when creating Rounds and Games for the first time for a Division to use the “Create Schedule” button.

Alternatively, you can delete all Rounds (which deletes its associated Games with it) to clear the Division of all Scheduling and then use the “Create Schedule” feature to recreate the Schedule from scratch if needed/desired.

Clicking the button will show you the following:

The top dropdown selector gives the options to schedule using “Round Robin” or “Tournament Brackets”. At this time only Round Robin scheduling is supported by this feature; Tournament Brackets will be supported in a future release of QView.

Making modifications to each field should be fairly intuitive. This dialog helps you by calculating the result of what would be scheduled if you were to use the current settings.

Once everything looks correct, click “Create Schedule” to create the Rounds and Games that you described using the fields of the dialog.

Edit Start Times button

Use this button to adjust the Start Times of the Division’s existing Rounds in bulk. When you click the button, you are presented with the following options:

Please take some time to read the notice in this dialog box. It is a simple interface: Set the date and time that the first Round is supposed to start, then define how much time should be in between the start of each Round. When you click ‘Apply’ it will adjust the start times of all Rounds by that offset. For instance, Round 1 = 7am, Round 2 = 7:30am, Round 3 = 8am, Round 4 = 8:30am, etc. (This modifies existing Rounds of the Division only.)

Once Done With Scheduling:

Please keep in mind, Scheduling may need to be updated if you ever add new Teams to the Division. This is a great reason to have hard registration cut-off dates - so that you have the appropriate amount of time for scheduling each Division of your Tournament.
