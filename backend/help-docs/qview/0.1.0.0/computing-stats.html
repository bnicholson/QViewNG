This article is for Tournament owners and admins who want standings for each Division. It covers how QView groups Games for stats, how to read Team and Individual stats, how to pull in Games from a Room that was offline (“sneakernet”), and how to export the results.

Before you start: you need to be the Tournament’s owner or one of its admins. Only those users see Server Stats in the Tournament sidebar.

What is a Stats Group?

A Stats Group is the set of Games that stats are computed from. QView makes one for you every time you create a Division, using the Division’s name. You don’t create or fill it yourself: when a Game is added to the Division (or moved into it), it joins the Division’s Stats Group automatically.

If you’ve used QMServer, this replaces creating a Stats Group/Tournament by hand. In QView, every Division already has one.

Where do you find stats?

There are two places:

  • Server Stats (owners and admins): Team and Individual stats for any Division, the tie-breaking rules, sneakernet importing and exporting.
  • LIVE Stats (everyone, even if they aren’t signed in): the Division’s Team standings, updating live as Games finish. It’s a good page to put on a projector.

Checking that every Game is ready

Stats only count Games that are finished and have complete data, so check the Games first.

  1. Open the Tournament and click Server Stats in the sidebar.
  2. In Divisions / Groups, pick the Division.
  3. In Data, pick Games Selection (it’s the default).

Each row is a Game. Games already in this Division’s Stats Group are ticked and listed first. The columns that matter most:

  • Question: how far the Game has got.
  • Done: Yes once the Game is finished.
  • DataOk: Yes when QView has every event it needs to score the Game.

If any Games aren’t ready, a banner above the table tells you how many. A red row means the Game reached question 20 but its data is incomplete. Its Information column says Data Incomplete. Resend Advised.

To fix a Game with missing data, click the No in its DataOk column. That opens the Room Monitor, where you can ask that Room’s QuizMachine to resend (see Monitoring Rooms and Resending Game Data). If the Room never had a connection, import its Games instead (below).

The Selected checkboxes only change what you see and what goes into an export. They don’t add Games to or remove Games from the Stats Group, and they aren’t saved.

Reading Team Stats

  1. On Server Stats, set Data to Team Stats.

You’ll see each Team’s Place, # Games, Wins, Losses, Olympic Points, Mod. Olympic Points, Total Points and Total Avg. Points, followed by the outs, fouls and question-type columns (see Question types, outs and fouls below).

A few things worth knowing:

  • Wins and losses are counted per opponent. Say three Teams quiz together: the 1st-place Team goes 2-0 for that Game, 2nd goes 1-1, and 3rd goes 0-2. In a 2-team Game it’s simply 1-0 and 0-1.
  • Olympic points are 8 and 3 in a 2-team Game, and 10, 5 and 1 in a 3-team Game. Modified Olympic points add to those based on each Team’s score.
  • Overtime questions don’t count toward the Team score used here.
  • Only finished Games count. A Game still in progress doesn’t change the standings until it ends.

Why is one Team above another?

Click the (i) in a Team’s Rank Rules column. A dialog explains which rule put the Team above the Team below it (and below the Team above it), with both Teams’ numbers. For example, “Rule 1 — Team W-L Record: 6-2, 4-4.”

Changing the tie-breaking rules

When Teams are level, QView separates them using a list of rules, top first. To change the order:

  1. On Server Stats with Data set to Team Stats, click Tie-breaking Rules.
  2. Drag a rule (or use its up/down arrows) to move it. Untick a rule to leave it out.
  3. Click Save.

The default order is Team W-L Record, Memory Verse (M) Correct, Head-to-Head W-L, Total Points, Total Avg Pts, Olympic Pts, Mod Olympic Pts. Head-to-Head only looks at the Games those Teams played against each other.

Using the Memory Verse (M) Correct rule

This rule puts the Team with more correct toss-ups on Memory Verse questions (every R, Q and V question) ahead. Bonuses don’t count. It starts unticked, so it only affects standings if you tick it.

It needs to know which questions are Memory Verse questions, so it stays greyed out until every Round of every Division in the Stats Group has question types. The grey note under it says so. To fill them in, click Set Question Types next to Tie-breaking Rules (see Setting Question Types for Rounds).

Set Question Types is greyed out when you’ve picked a Stats Group that isn’t a Division’s, because question types belong to a Division’s Rounds. Pick each Division’s own Stats Group instead.

When you save, Team Stats re-sorts straight away, and so does LIVE Stats for everyone watching.

If you untick every rule, level Teams are simply listed in alphabetical order. Places are never shared between Teams: if two Teams are still level after every rule, alphabetical order decides.

Reading Individual Stats

  1. On Server Stats, set Data to Individual Stats.
  • Score is the Quizzer’s points without bonus points. Bonus points are shown on their own in Bonus Pts.
  • Avg is Score divided by # Games.
  • Errors counts wrong answers on toss-up questions. Bonus Attempts counts every bonus they tried, right or wrong.
  • Quizzers are ranked by highest Score, then fewest Errors. Quizzers with the same Score and Errors share a place, and the next place is skipped (1, 1, 3).

Errs 16+/5+ is always blank.

Teams and Quizzers are matched by name. If a name was typed differently in a Room, it shows up as a separate row, so fix the name in QView and resend or re-import that Game.

Question types, outs and fouls

Team Stats and Individual Stats both have these columns. For a Team, every count adds up its Quizzers.

Quiz Outs, Error Outs, Foul Outs and Fouls

  • Quiz Outs: how many times they quizzed out. Hover over the number to see how many were with no errors and how many were with errors. Only a quiz out with no toss-up errors in that Game earns the quiz-out points.
  • Error Outs: how many times they errored out.
  • Foul Outs: how many times a Quizzer reached the Game’s foul limit (normally 3).
  • Fouls: every foul. For a Team, this also counts team and coach fouls. Hover over the number to see Quizzer, Team and Coach fouls separately.

The question-type columns

There’s a column for each question type: G, A, M, R, Q, V, X, I and S. Each shows correct toss-ups out of toss-ups answered. Say a Team shows 7/9 under G: its Quizzers answered 9 General toss-ups and got 7 right. Hover over the number to see the bonus counts too, or over a column heading for the type’s full name. A dash means none were answered.

  • M (Memory Verse) counts the R, Q and V questions again, together.
  • Only questions with a type count. Overtime questions, and every question in a Round without question types, are left out. If every column shows a dash, the Rounds don’t have question types yet (see Setting Question Types for Rounds).

Seeing the full breakdown

Click a Team’s or Quizzer’s row. It opens to show two tables:

  • Question Types: Attempted, Correct, Bonuses Attempted and Bonuses Correct for each type. The Total column leaves out M, because M repeats R, Q and V.
  • Outs & Fouls: Quiz Outs split into No Errors and With Errors, Error Outs, Foul Outs and Fouls. For a Team, Fouls is split into Quizzer, Team and Coach. Each split has a Total.

Click the row again to close it. On a phone, the two tables sit one under the other.

Clicking the (i) in Rank Rules opens its dialog without opening the row.

Showing live standings with LIVE Stats

  1. Open the Tournament and click LIVE Stats.
  2. Click the Team Stats tab and pick the Division.

The table updates by itself as Games finish. The indicator in the corner tells you how it’s staying up to date: Live is best. Refreshing every 30s means the live connection dropped and the page is checking every 30 seconds instead.

The page’s address remembers the Division you picked, so you can bookmark it or open it on a projector and it will stay on that Division.

If you see No games in this division have finished yet, nothing has ended in that Division yet. Teams appear as their first Games end.

LIVE Stats and Server Stats always agree. Server Stats doesn’t update by itself, though: switch views or reload it to see the latest.

Importing Games from an offline Room (sneakernet)

If a Room’s QuizMachine couldn’t reach QView (no internet, say), its Games never arrived. You can bring them in by exporting them from QuizMachine to a USB drive and importing the file into QView. When you use your sneakers to physically transport the stats and then import them into QView, you're using "sneakernet".

You’ll need: permission to update Games in this Tournament, and the Room’s Games exported from QuizMachine as a .csv file (see Exporting Quiz Round Data from QuizMachine). Only Games marked DONE in QuizMachine are exported.

  1. On Server Stats, set Data to Games Selection.
  2. Click Import (SneakerNet) and choose the .csv file.
  3. Read the preview. Nothing has been saved yet.
  4. If the Games to Import list looks right, click Import.
  5. When you see Imported game events for N game(s)., click Close.

The preview has four lists:

  • Games to Import: Games that will come in, with how many events each has.
  • Errors: Games that will be skipped, and why.
  • Games Not Found: Games in the file that QView couldn’t match to a Game in this Tournament.
  • Missing Game Events: other Games in the same Rooms that aren’t in the file. This is a reminder in case you meant to export them too.

How does QView match a Game? By the Tournament name, Division name, Room name and Round name in the file. They must match what’s in QView exactly (the Tournament name can also be blank). Games are imported together, and any Game with a problem is skipped rather than stopping the import.

When the import doesn’t work

  • “Only .csv files are accepted.” Choose the .csv file QuizMachine exported (usually Quizzes.csv).
  • A Game is under Games Not Found. A Division, Room or Round name in QuizMachine doesn’t match QView. Check the spelling in both places.
  • “This game already has game events beyond initialization; import skipped.” QView already has that Game’s quiz data, from the Room or an earlier import. Importing the same file twice is safe; this is why.
  • “Parsing error: …” The file isn’t in QuizMachine’s export format (for example, it was edited in a spreadsheet). Export it again from QuizMachine.
  • “question numbers are not sequential” or “missing event number” Part of the Game is missing from the file. Re-export it from that Room’s QuizMachine.

Exporting results

  1. On Server Stats, pick the Division and the Data view you want: Team Stats, Individual Stats or Games Selection.
  2. Click Export and choose CSV (.csv), Excel (.xlsx) or PDF (.pdf).

The file downloads straight away, named after the view (team-stats, individual-stats or game-selection). It contains the whole table, not just the rows on screen. In Team Stats exports, the Rank Rules column is written out in words. PDFs of Team and Individual stats print in landscape.

Team and Individual exports also include the full breakdown from each row, one number per column:

  • Outs and fouls: QO No Errors, QO With Errors, QO Total, Error Outs and Foul Outs, then Fouls for a Quizzer, or Quizzer Fouls, Team Fouls, Coach Fouls and Fouls Total for a Team.
  • Question types: four columns for each type, such as G Attempted, G Correct, G Bonuses Attempted and G Bonuses Correct.

The Export button is greyed out when the table is empty. Pick a Division that has finished Games.
